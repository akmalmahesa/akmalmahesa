Rentify — A rent website

A vehicle rental website designed to help traditional rental businesses digitize their booking process.

Role
UI/UX Designer, Front End, Back End
Tools
Figma, Laravel
Project Type
Academic Project

Problem Statement

Many small vehicle rental businesses still rely on manual booking processes such as phone calls or in-person reservations. This approach can make rental management inefficient and inconvenient for customers who want quick access to vehicle availability and booking information. A digital platform can help simplify the rental process while improving accessibility for customers.

Design Goals

  • Create a clear and simple vehicle rental interface for quick booking.
  • Help traditional rental businesses transition from manual to digital systems.
  • Provide an easy way for users to browse available vehicles and rental details.
  • Ensure the booking flow is straightforward and accessible for first-time users.

Design Process

ResearchAnalyzed existing rental platforms to understand common booking flows, vehicle browsing behavior, and usability expectations.
WireframesDesigned initial wireframes focusing on vehicle browsing, rental details, and a simple booking flow to reduce friction during reservations.
UI ExplorationDeveloped a clean and structured interface in Figma, prioritizing readability, vehicle visibility, and intuitive navigation for users searching for rental options.
Design DecisionsFocused on simplifying the rental experience by organizing vehicles into clear categories—cars, motorcycles, and bicycles—while keeping the booking process straightforward.

Final Design

Key Takeaways

This project helped me understand how UI design translates into real web development, particularly when implementing interfaces using Laravel.

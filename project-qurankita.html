UI Design

QuranKita

A mobile Quran application designed to support daily Islamic practices through accessible religious features.

Role
UI Designer
Tools
Figma
Project Type
Competition Project

Problem Statement

Many Quran applications focus only on reading features or present too many functions in a cluttered interface. This can make it difficult for users to quickly access essential tools needed for daily worship. A well-structured mobile application can help integrate Quran reading with other important Islamic features in a simple and accessible way.

Design Goals

  • Provide a clean and comfortable Quran reading experience on mobile devices.
  • Integrate essential daily worship tools into one application.
  • Ensure users can quickly access features such as prayer times, Qibla direction, and dua.
  • Design an interface that remains simple and easy to navigate.

Design Process

ResearchReviewed existing Quran applications and analyzed common features used for daily worship, such as prayer times, Qibla direction, and supplication collections.
WireframesCreated wireframes focusing on the Quran reading interface and clear navigation between core features such as prayer times, Qibla finder, and the Hijri calendar.
UI ExplorationDesigned a calm and minimal interface in Figma, prioritizing readability for Quran text and clear visual hierarchy for supporting features.
Design DecisionsFocused on integrating multiple worship tools—Quran reader, prayer times, Qibla finder, Hijri calendar, and dua collections—while maintaining a clean and uncluttered interface.

Final Design

Key Takeaways

This project strengthened my ability to design utility-focused mobile applications. I learned how to balance multiple features within a clean interface while maintaining accessibility and ease of use.
